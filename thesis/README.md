# Thesis Workspace

LaTeX пояснительная записка (без титульных листов):

```powershell
.\thesis\build.ps1
```

- `latex/` — исходники и сборка (`master-thesis-pz-body.tex`)
- `scripts/` — порт Markdown → LaTeX, фигуры, sync kit
- `pz-latex-kit/` — автономный kit для сборки в Docker
- `presentation/` — шаблон презентации ВКР

Upstream-шаблон кафедры (только справочно): `thesis/_upstream-thesis-template/`
